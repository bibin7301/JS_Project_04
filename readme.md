Counter App
[live@](https://counterapp04.vercel.app/)

A simple and interactive Counter App built using HTML, Tailwind CSS, and JavaScript.
Users can increase, decrease, and reset the counter value with dynamic color changes based on the count.

🚀 Features
➕ Increase counter value
➖ Decrease counter value
🔄 Reset counter to zero
🎨 Dynamic color changes:
Green → Positive values
Red → Negative values
Blue → Zero
📱 Responsive UI using Tailwind CSS
🛠️ Technologies Used
HTML5
Tailwind CSS
JavaScript (DOM Manipulation)
